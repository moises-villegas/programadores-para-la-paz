5 prácticas de seguridad para plataformas digitales comunitarias — Semana 8

1. No exponer datos personales de los usuarios en respuestas de la API ni en
   archivos públicos. La información sensible debe estar protegida y solo
   accesible para quienes tienen autorización.

2. Proteger credenciales de acceso usando contraseñas fuertes y únicas para
   cada servicio. Nunca guardar contraseñas en texto plano dentro del código
   fuente ni en repositorios públicos como GitHub.

3. Usar conexiones seguras mediante HTTPS para cifrar la comunicación entre
   el servidor y los usuarios, evitando que terceros puedan interceptar los datos
   que se transmiten.

4. Registrar accesos y actividad del sistema mediante logs, para poder identificar
   comportamientos sospechosos, intentos de acceso no autorizados o errores que
   puedan comprometer la seguridad de la plataforma.

5. Limitar el acceso a información sensible según el rol de cada usuario, aplicando
   el principio de mínimo privilegio: cada persona o proceso solo debe tener acceso
   a lo estrictamente necesario para cumplir su función dentro de la plataforma.
