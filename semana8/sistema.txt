Información del sistema — Semana 8

--- Comando: uname -a ---
Este comando muestra información completa sobre el sistema operativo y el kernel.
La salida incluye: el nombre del sistema operativo, el nombre del host (computador),
la versión del kernel, la fecha de compilación y la arquitectura del procesador.
Es útil cuando se administra un servidor porque permite verificar qué versión del
sistema está corriendo, lo cual es clave para saber si hay actualizaciones de
seguridad pendientes y si el entorno es compatible con el software que se va a instalar.

--- Comando: whoami ---
Este comando muestra el nombre del usuario con el que se está trabajando actualmente
en la terminal. Es útil en la administración de servidores porque permite saber
con qué nivel de privilegios se están ejecutando los comandos. Si el usuario es
"root", se tienen permisos totales sobre el sistema, lo cual implica mayor
responsabilidad y riesgo. Conocer el usuario activo ayuda a evitar errores graves
por ejecutar comandos con permisos que no se deberían tener en ese momento.

--- ¿Por qué es útil conocer información del sistema? ---
Cuando se administra un servidor, conocer el sistema operativo, la versión del
kernel y el usuario activo permite tomar decisiones más seguras y precisas. Ayuda
a diagnosticar problemas, aplicar configuraciones correctas y mantener el servidor
protegido frente a posibles vulnerabilidades.
